# TKJ Network Adventure - Versi Gabungan

Project ini menggabungkan:
- 4 level kuis TKJ dari `TKJ Network Adventure`
- Level 5 berupa game Ular Tangga TKJ dari project `game-ular-tangga-tkj`
- Semua berjalan dalam satu `index.html`, `style.css`, dan `script.js`
- Progress level disimpan di localStorage

## Menjalankan
1. Buka folder ini di VS Code.
2. Gunakan Live Server.
3. Buka `index.html`.
4. Selesaikan Level 1-4 untuk membuka Level 5 Ular Tangga.

## Struktur
- `index.html` UI utama + UI ular tangga
- `style.css` style utama + style ular tangga
- `script.js` logika kuis + logika ular tangga
- `data/levels.json` soal Level 1-4
