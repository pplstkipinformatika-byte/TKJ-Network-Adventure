    Cara bermain

    • Bergiliran melempar dadu. Klik “Lempar Dadu”, token akan maju sesuai angka yang keluar.
    • Tangga (🪜) membawa token naik lebih cepat menuju petak 100.
    • Ular (🐍) membuat token meluncur turun ke petak yang lebih rendah.
    • Petak soal (❓) memunculkan pertanyaan seputar jaringan komputer. Jawaban benar → token tetap di tempat. Jawaban salah → token mundur 1–2 langkah secara acak.
    • Token harus mendarat tepat di petak 100 untuk menang — jika angka dadu melebihi sisa langkah, giliran berpindah tanpa bergerak.
    • Pemain pertama yang mencapai petak 100 dinyatakan menang.
